# 测试目录

离线测试验证通用文字聊天的参与策略、共享群上下文、消息调度和微信适配边界，使用虚构账号/群 ID、消息及模拟模型/网关。不得复制真实微信数据库、凭据、API 密钥或完整聊天正文作为测试数据。

```powershell
uv sync --extra native
uv run --extra native python -m unittest discover -s tests -v
```

本轮重点验证以下行为，具体已通过项以实际测试输出为准：

- 白名单、暂停、原生 `@` 回答，以及普通消息自然接话/沉默。
- 空资料目录不阻断聊天；自然参与无效格式按沉默处理。
- 持久模式按群恢复最近 50 条、原顺序与回复对象，旧记录不过期、历史不触发推理或发送；未启用存档的独立临时 ChatService 仍验证 20 条/10 分钟边界。
- 用户记录与去重、助手记录与确认状态的事务回滚/幂等，完整正文存档与模型窗口限制、撤群隔离、旧库迁移、身份密钥保护及独立 CLI 重启恢复。
- 场景表情包：公开索引同步与官方精选回退、静态图片/单帧 GIF/路径约束、长边缩放到 500 像素、1000 像素硬上限、文字与 `meme_id` 同次返回、坏 ID 保留文字、冷却与最近避重、文字确认后才配图、图片回执/未知不重发、媒体历史标记及撤群隔离。
- 稳定 API 成员名、当前说话人与历史回复对象、同名/改名及人设变化、昵称作为用户数据、定向微信昵称查询及失败降级。
- 模型空响应/坏 JSON/截断/HTTP 协议错误分类、有界恢复、重试计配额、认证不重试，以及失败后新消息继续处理。
- 自然参与决策工具：强制 `decide_reply`、空回复=沉默、`null` 归一、坏参数/错误工具名/截断、纯文本回退，避免 JSON Output 空内容被误判为必须重试的错误。
- 消息持久去重（含沉默）、不同参与分支的冷却、每小时模型调用配额。
- 模型主机限制、缺少密钥、调用异常与发送失败/未知状态。
- 原生 `source.atuserlist`、手打 `@`、Zstandard 压缩、损坏/超限输入、自发消息和稳定消息身份。
- 原生拍一拍的群/发起人/目标校验、空数据库发送人解析、自拍/拍别人拒绝、严格 XML 与压缩边界；独立直接互动、按人设文字回应、去重/暂停/冷却与取消待处理自然批次。
- 拍一拍先入库后补齐服务器编号时保留游标，确认后只处理一次。
- 网关启动游标、新消息读取、账号/版本/监听归属校验与只读检查边界。
- 独立云端翻唱命令、准备不上传、Kits multipart/任务身份/下载边界、提交未知不重提、轮询恢复、女声名单、分轨跳过分离及音频时长/静音/峰值检查。测试使用虚构服务与合成音调，不能证明云端翻唱效果。

测试数量随实现变化，不固定总数。离线测试通过不代表真实微信、DeepSeek 和持续运行已联通。

本机基础读取、单次发送回执和原生 `@` 的既有结果见 [接入历史记录](../docs/wechatagent-integration.md)。本轮 DeepSeek 真实 `@` 回复与自然接话均已取得服务器回执并由用户收取，见 [文字聊天验收](../docs/chat-acceptance.md)。长期运行检查见 [workflow.md](../workflow.md)。语音合成、原生语音条与唱歌按后续阶段分别验证。
