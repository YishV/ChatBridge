# 表情包与云端点歌翻唱方案

日期：2026-10-20。状态：方案草案，供用户评审；本文不代表媒体功能已经实现。

## 已确定的方向

- 保留现有 DeepSeek 文字聊天、自然接话、人设和拍一拍。
- 唱歌目标是演唱指定的现有歌曲；第一轮采用云端翻唱与现成女声音色，试听后再选择固定歌声。
- 表情包与翻唱分别交付。图片、音频文件和微信原生语音条分别验收。

## 当前能力与缺口

项目发送接口目前只有文本。已下载的微信参考组件有图片发送入口，但本项目尚未完成图片适配、发送确认和现场验证。动图、原生收藏表情、音频文件和原生语音条均不能视为已有能力。

翻唱需要歌曲的实际音频及演唱信息。只有歌名不足以生成保留指定旋律的可靠翻唱。第一版采用管理员登记的本地测试歌曲，不接自动搜歌、任意网络下载或群友上传文件。

## 服务选择

对比过本地与云端两条路线，用户已选择云端。首个候选为 Kits：其官方页面和文档目录列出声音转换、现成声音库、人声分离及异步任务查询能力。先确认实际账号 API 权限、可用模型和用量，再进行试听，不把网页工具权限等同于 API 权限。

中文咬字、音域适配和人声分离质量均以试听结果判断，不能由声音库的女声标签推定效果。固定记录每次试听的模型标识和处理参数，便于比较。首轮选择一个可用女声，效果不合适再换，避免同时生成大量付费用量。

## 分阶段交付

### A. 云端翻唱短样

建议以同一首歌曲约 20 秒片段试听；具体开始位置由管理员给定，未指定时采用第一段适合试听的演唱片段，并在处理前列明。

流程：本地准备片段 → 云端分离人声与伴奏 → 转换为选定女声 → 混音与音量检查 → 本机试听。

- 只上传本次选择的歌曲片段，不向翻唱服务发送群聊或微信凭据。
- 若输入已有独立人声和伴奏，可跳过分离。
- 第一轮由本机显式命令执行，不先接进群消息调度。
- 输出保存在 Git 忽略的运行目录，附非敏感处理状态。首次试听不向微信群自动发送。
- 密钥通过本机配置读取，不放进聊天、示例配置、命令参数、日志或文档。
- 提交任务后保存服务任务标识，轮询有超时和次数上限。提交响应不明确时不重复提交付费任务；先查状态或交由本机检查。
- 若账号不具备 API 权限，停止该候选的实际调用，说明缺失条件后再评估其他服务。

验收：用户能播放短样，确认歌曲旋律与歌词匹配、女声可接受、伴奏同步，输出没有明显削波或异常静音。成功生成文件不能证明微信发送可用。

### B. 本地表情库与图片发送

先实现受控的静态图片库：每张图有素材 ID、情绪标签和简短说明。模型只返回已登记素材 ID，程序解析到允许目录中的文件；不允许模型指定任意路径或下载地址。

先验证一张图片的授权群发送和确认，再让 AI 结合人设选择是否配图。每次回复最多一张，增加独立图片冷却，近期已发图片避免重复。没有合适素材时只回文字。发送状态不明确时不自动补发。GIF 动画和微信原生表情后续单独验证。

验收：授权群收到指定图片；错误素材 ID 不发送；白名单、暂停、去重有效；文字成功而图片失败时不重发文字。

### C. 群内点歌与歌曲音频发送

在 A 试听通过后，把认可的歌曲和音色登记为本机曲库。识别明确点歌请求，按歌名和歌手匹配；重名先澄清，不存在则说明曲库未收录，不随意换歌。

翻唱使用独立后台任务，聊天处理不等待音频生成。初期单任务并发，设置队列容量、歌曲时长和每日调用上限。重复点歌可复用同一歌曲、音色和参数的已完成结果。持久任务记录和恢复行为在本阶段实施前细化并评审。

接收请求、生成完成和投递是不同状态。暂停或撤销群后不发送后台完成的音频；发送前重新校验微信账号、群与发送资格。状态未知时不自动重复生成或发送。

先验证可播放音频文件的群内发送。原生语音条采用另一项适配和验收，未通过前不承诺显示为语音条。完整歌曲的文件大小和发送方式在实际组件能力核验后确定。

验收：群友点指定曲库歌曲后能收到并播放；生成期间文字聊天正常；重复请求和未知状态不会造成重复发送。

## 拟定模块边界

- `media/catalog`：素材 ID、歌曲信息与受控本地文件路径。
- `media/providers`：云端声音目录、任务提交、状态查询和结果获取，与 DeepSeek 适配分离。
- `media/audio`：裁剪、混音和格式检查，外部音频工具按实际安装情况选用。
- `wechat`：图片及音频发送适配，分别实现和验证确认机制。
- `dispatch`：后续点歌任务入口、队列及配额，不在文字回复路径执行长任务。

以上为拟定职责，不要求提前创建所有目录或引入完整任务框架。首轮先实现可独立验证的短样链路。

## 实施前所需信息

1. 候选服务账号是否具有可用 API 权限，以及实际可调用的现成女声。密钥只在本机配置。
2. 试听歌曲名、歌手及本机音频路径；如有指定片段，提供起止时间。
3. 用户评审本方案。后续会涉及发送接口、消息调度和任务状态，按项目 AGENTS.md 在实施前确认范围。

在服务与素材准备期间，可以继续完善离线适配设计；不为验证而读取其他群或自动购买服务。

## 验证安排

- 服务适配使用虚构响应，覆盖任务成功、失败、超时、损坏结果和提交状态不明确。
- 素材目录覆盖越界路径、未知素材 ID、不可读文件和大小限制。
- 发送适配覆盖白名单撤销、暂停、部分失败和未知回执。
- 现场按短样本机试听、单张图片、音频文件、群内点歌的顺序分别记录结果。未完成项明确保留为待验收。
