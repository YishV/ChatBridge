# 显式看图实施计划

## 已确认范围

沿用现有框架及 DeepSeek Flash。授权群内，同一群友先发一张普通图片，再从微信成员列表 @ 机器人要求看图，识别该成员最近两分钟内的最后一张图。每次一张；不自动识别普通图片、不处理他人的图、不回放启动前图片。用户已在授权测试群发送指定测试图用于核验。

## 实现任务

- 入站只登记图片的完整消息身份（群、成员、shard/local_id/server_id/create_time），不登记本地路径或原图；新图替换同一人的旧图，有界且短时过期。
- 请求看图时再次核验账号、群权限和原始消息身份；使用该消息的资源记录定位当前群附件目录。只读取精确文件，不扫描其他聊天图片；V2 本地媒体密钥只从该沙盘的 kvcomm 文件名推导并用目标文件验证，不扫描进程内存。
- 图片只在内存解码，限制字节、像素和尺寸，单帧转 JPEG、纠正方向并剥离元信息；不下载任意网络图片，不把文件路径、消息 XML 或本地密钥传给模型。
- 新增受限视觉输入方法；按当前人设与稳定成员上下文回复。所有调用继续通过现有模型配额、重试、暂停和去重边界；取不到图明确说明，不猜图。
- 原图不进 SQLite，不带入之后模型轮次；只保存现有用户问题与已确认文字回复。
- 配置开关、只读状态与文档；离线测试覆盖同群同人、超时、新图覆盖、消息身份、资源路径、解码、敏感数据不进入模型请求及普通功能回归。用明确测试图核验，机器人由用户自行重启。

## 验证记录（2026-10-21）

- 完整离线回归：共 372 项，370 项通过，2 项跳过；最终请求规则专项：共 50 项，49 项通过，1 项跳过。跳过包含 Windows 符号链接权限限制；实际 junction 路径拒绝另有覆盖。
- 审查修复：否定、引用转述、能力咨询不作为看图授权；同分片同秒按本地序号选图，不依赖服务器编号大小；跨分片同秒顺序不明时保留歧义标记并要求重发；启动前迟到或未确认图片不登记、不阻塞新图片游标。
- 只读接入检查通过，图片开关与 120 秒窗口生效；语音条仍关闭。未启动或重启机器人。
- DeepSeek 对合成图片上的固定文字读取正确；用户指定的新普通图片可从精确微信缓存解析，并完成真实视觉请求获得文字。原图只在内存处理，未向群发送或写入公共测试夹具。
- 原指定 GIF 的当前本地副本格式尚不能解码，生产路径明确降级，不猜图。首版支持标准 GIF 首帧，不宣称支持所有微信表情缓存或原生收藏表情。
- 用户自行重启后，需重新先发图，再在有效期内原生 @ 要求看图；本次离线指定样本验证不回放成群回复，完整群内收发仍待用户验收。
