# QQ 原生表情与戳一戳

QQ 侧支持两种附加动作，由模型在回复时自行决定：

```text
face_id   QQ 原生小黄脸
poke      回复后戳一戳当前说话人
```

群聊和私聊都支持；微信不会启用这两个动作。

## 模型怎么决定

模型在 `decide_reply` 工具里额外看到：

```text
face_id  可选原生表情编号，默认空字符串
poke     是否戳当前说话人，默认 false
```

提示词要求：

- 大部分回复不要附加动作
- 情绪明显、撒娇、回击、被戳时才可以戳回去
- 不能声称执行了没有执行的动作

模型返回 `face_id` 或 `poke` 后：

```text
文字回复 → 表情包图片（如有）→ 原生表情（如有）→ 戳一戳（如有）
```

## 支持的接口

NapCat/OneBot：

```text
face segment                发送 QQ 原生表情
group_poke                  群聊戳一戳
send_poke                   私聊戳一戳
```

收到的戳一戳：

```text
notice_type=notify
sub_type=poke
target_id=机器人
```

群聊和私聊都会映射成：

```text
interaction=pat
```

因此机器人被戳后可以自然回应，也可以偶尔戳回去。

## 表情编号

内置了经典 QQ 小黄脸编号表，例如：

```text
13  呲牙
14  微笑
19  偷笑
21  白眼
31  疑问
41  鼓掌
```

完整表在 `src/wechat_ai_bridge/faces.py`。

## 注意

- 原生表情是 QQ 功能，微信消息不会使用
- 戳一戳没有冷却，模型提示词要求克制；如果实际使用中出现刷屏，应加频率限制
- 失败只记录日志，不影响文字回复
- `poke` 和 `face_id` 都是可选项，模型可以永远不选
